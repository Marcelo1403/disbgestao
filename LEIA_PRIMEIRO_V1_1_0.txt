DISB GESTAO v1.1.0 - MODULO PUXADA

1) Execute supabase/08_v1_1_0_modulo_puxada.sql no SQL Editor do Supabase.
2) Extraia esta versao na raiz de C:\disbgestao-git substituindo os arquivos existentes.
3) Republique a Edge Function admin-users para habilitar o perfil MOTORISTA_PUXADOR.
4) Rode npm install e npm run android:sync antes de gerar o APK.
5) Teste com dois usuarios Motorista Puxador antes de liberar a operacao.

IMPORTANTE SOBRE GPS:
- Cada etapa captura GPS/data/hora.
- O percurso usa pontos de rastreio enquanto o app mantem a geolocalizacao ativa.
- Esta versao nao instala um servico Android nativo permanente para rastrear com o aplicativo totalmente encerrado.
