DISB GESTAO v1.3.0 - CONTAGEM FEFO

ORDEM RECOMENDADA

1) Faça backup do banco / confirme que seus dados reais estão preservados.
2) No Supabase SQL Editor execute:
   supabase/17_v1_3_0_contagem_fefo.sql
3) Aplique os arquivos da v1.3.0 na raiz do projeto.
4) Opcional: importe bases_fefo/PRODUTOS_DISBSTOCK_V1_6.csv em
   Administracao > Bases / importacao > PRODUTOS.
5) Opcional: copie o pacote de imagens do DisbStock para imagens_produtos/.
6) Rode npm install, se necessario.
7) Rode npm run android:sync.
8) Gere o APK normalmente.
