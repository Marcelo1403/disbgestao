DISB GESTAO v1.1.4

1. Execute no SQL Editor do Supabase:
   supabase/10_v1_1_4_gps_motorista_dashboard.sql

2. Depois publique os arquivos desta versao no GitHub.

3. Para o APK:
   npm install
   npm run android:sync
   cd android
   .\gradlew.bat clean
   .\gradlew.bat assembleDebug

GPS:
- O limite configuravel agora vai de 5 a 30 metros.
- No Android, mantenha Localizacao Precisa ativada para o Disb Gestao.
